# Matriz de evidencias · «Las manos que construyeron la historia»

Protocolo ARQ-3D-01, fase 1, adoptada de forma parcial. Para cada elemento reconstruido se indican la afirmación, la fuente y el grado de certeza:

- **Documentado:** lo respalda una fuente citada.
- **Interpretado:** es una hipótesis o un debate abierto, y se presenta como tal en el recurso.
- **Modelo didáctico:** es una simplificación o un dato inventado, declarado en la actividad.
